# 🤖 AI Generator

A AI-web application that do text-generation, para-generation and also provide facility of AI chatbot and javascript convertor

---

## 🌐 Live Demo

https://kraftysoul-ai.onrender.com/

---

## 🛠 Tech Stack

- **Frontend**: React, Axios, custom CSS  
- **Backend**: Node.js, Express  
- **AI Integration**: Gemini API   
- **Authentication**: JWT-based user sessions  
- **Deployment**: Frontend and Backend hosted on Render

---

## 🔍 Core Features

- User signup and login with JWT  
- Prompt-based text generation  
- Prompt-based para generation   
- Responsive UI with light and dark mode support
